# Zontes Voice V.2

แอพ Android สั่งรถ Zontes ด้วยเสียง โดยให้ Accessibility Service เปิดแอพ Zontes Smart แล้วกดปุ่ม LOCK / UNLOCK / FUEL / SEAT แทนมือ
มีไอคอน HUD ลอยบนหน้าจอ (ชื่อกลางวงแก้ได้ ค่าเริ่มต้น F.R.I.D.A.Y)

## Build
1. เปิดโฟลเดอร์นี้ด้วย Android Studio (Koala หรือใหม่กว่า) แล้วรอ Gradle Sync
2. ต่อมือถือ (เปิด USB debugging) แล้วกด Run หรือ Build > Build APK

## ตั้งค่าครั้งแรกบนมือถือ (Xiaomi)
1. เปิดแอพ > "อนุญาตไมค์ + การแจ้งเตือน"
2. "เปิด Accessibility" > เลือก Zontes Voice > เปิด
   (ถ้าเปิดไม่ได้ ไปที่ ตั้งค่า > แอพ > Zontes Voice > ⋮ > อนุญาตการตั้งค่าที่ถูกจำกัด)
3. "อนุญาตแสดงทับแอพอื่น" (ใช้ทั้งเปิดแอพ Zontes จากเบื้องหลัง และแสดงไอคอนลอย)
4. ตั้งค่า > แอพ > Zontes Voice > เปิด Autostart และตั้งแบตเตอรี่เป็น "ไม่จำกัด"
5. "เลือกแอพ Zontes Smart" แล้วกด "ทดสอบ UNLOCK / LOCK" ให้ผ่านก่อน
6. กด "เริ่มฟังเสียง" จะมีไอคอนลอยขึ้น

## ไอคอนลอย
- วงแหวนหมุน = กำลังฟัง / หมุนเร็วสีส้ม = กำลังสั่งรถ
- แตะ 1 ครั้ง = หยุดฟัง (ภาพหยุดนิ่งสีหม่นพร้อมสัญลักษณ์ play) แตะอีกครั้ง = เล่นต่อ
- ลากเพื่อย้ายตำแหน่ง (จำตำแหน่งไว้) ปรับขนาดได้ในหน้าแอพ
- **ปิดแอพ:** ลากไอคอนลงไปที่ปุ่ม X ที่โผล่ด้านล่างจอ (ไอคอนจะถูกดูดเข้าไปกลางปุ่ม) แล้วปล่อย
- วงในเรืองตามระดับเสียงพูด ถ้าพูดแล้วไม่เรืองเลย แปลว่าไมค์ไม่ได้ยิน
- ระหว่างกำลังสั่งรถ ไอคอนจะทะลุการสัมผัสชั่วคราว กันบังปุ่มในแอพ Zontes
- ถ้าไม่ให้สิทธิ์แสดงทับ จะไม่มีไอคอน แต่ใช้ปุ่ม "หยุด/เล่นต่อ" ในแจ้งเตือนแทนได้

## แก้ชื่อและวลีสั่ง
ในหน้าแอพ แก้ได้ทั้งชื่อ/คำปลุก และวลีของแต่ละคำสั่ง คั่นด้วย `,` ใส่หลายแบบได้
ตัวอย่าง: `friday เปิดการทำงานเครื่องยนต์` = UNLOCK
ถ้าวลีซ้อนกัน (เช่น "ล็อก" อยู่ใน "ปลดล็อก") ระบบเลือกวลีที่ยาวกว่า
ควรใส่คำปลุกเผื่อการถอดเสียงหลายแบบ เช่น `friday,ฟรายเดย์` เพราะ Google อาจถอดเป็นไทยหรืออังกฤษ

## ถ้าสั่งเสียงแล้วไม่ทำงาน
เปิดหน้าแอพ ดูช่อง "ผลการฟังล่าสุด" จะเห็นว่าแอพถอดเสียงเป็นข้อความอะไร และผลเป็นอย่างไร
- `→ ไม่ตรงคำปลุก` = ถอดชื่อผู้ช่วยมาไม่ตรง ให้เพิ่มคำที่ถอดได้ลงในช่องคำปลุก
- `→ ไม่ตรงวลีคำสั่งใด ๆ` = ได้ยินชื่อแล้วแต่วลีไม่ตรง ให้เพิ่มวลีที่ถอดได้ลงช่องของคำสั่งนั้น
- `เสียงสูงสุด ≈ -2 dB` ทั้งที่พูดอยู่ = ไมค์ไม่ได้ยินเสียง (มักเกิดเมื่อมีแอพอัดหน้าจอ/แอพอื่นใช้ไมค์พร้อมกัน)
- ลองเว้นช่องคำปลุกให้ว่างชั่วคราว เพื่อทดสอบว่าวลีคำสั่งทำงานไหม

## ข้อจำกัด
- ต้องกดเริ่มฟังจากในแอพหลังรีบูตทุกครั้ง
- ถ้าตั้งล็อกหน้าจอมือถือแบบ PIN/ลายนิ้วมือ ตอนจอล็อกอยู่ Accessibility จะกดปุ่มในแอพไม่ได้
- ชื่อปุ่มต้องตรงกับในแอพ Zontes (LOCK, UNLOCK, FUEL, SEAT) ถ้าเปลี่ยนให้แก้ `label` ใน `CommandParser.kt`
- รหัสลับต้องพูดออกเสียง จึงกันได้แค่คนพูดมั่ว ๆ
